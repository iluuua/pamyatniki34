# Дизайн и контент

Сдержанная мастерская: глубокий зелёный из предоставленной вывески, светлый фон камня, графитовый текст. Заголовки Cormorant Garamond, основной текст Manrope, кириллица. Прямоугольные фотографии и тонкие разделители. Основное действие — бесплатная консультация по телефону.

Разделы: первый экран, сроки, услуги, работы, художественное оформление, принадлежности, порядок заказа, стоимость и рассрочка, контакты с Яндекс Картой, реквизиты.

Факты: дизайн-проект за два дня; изготовление до двух месяцев; гранит/мрамор; доставка, установка, облицовка, благоустройство и разовая уборка; цена договорная; рассрочка возможна. Условия рассрочки не придуманы. Отзывы, стаж, гарантии и фиксированные цены не добавляются без данных.

Предоставленные фотографии включены как примеры работ, без ретуширования или генерации вымышленных объектов. Изображения вывески и скриншот реквизитов используются только как контекст.

Публикация: пользователь явно запросил свой GitHub и ссылку GitHub Pages. Поэтому Sites используется для исходного scaffold и принципов реализации; хостинг Sites не регистрируется, чтобы не создавать вторую незапрошенную публикацию.
